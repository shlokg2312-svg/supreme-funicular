\# Freelancer CRM — Database Portfolio



\## Overview

A sample PostgreSQL database designed to help freelancers

organize clients, potential leads, projects, and interactions.



\## Database Tables

\- Clients: stores client details.

\- Leads: tracks potential clients and their status.

\- Projects: stores projects associated with clients.

\- Interactions: records communication with leads.



\## SQL Concepts Demonstrated

\- SELECT, WHERE, and ORDER BY

\- COUNT and aggregate queries

\- GROUP BY and HAVING

\- JOIN across related tables

\- Primary keys and foreign keys



\## Project Files

\- schema.sql — creates tables and inserts sample data.

\- data-model.md — documents tables and relationships.

\- queries.sql — contains example SQL queries.



\## Technology

PostgreSQL, SQL, Git, and GitHub.



\## Purpose

A learning portfolio project demonstrating relational database

design and basic SQL querying.
